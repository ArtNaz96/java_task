# Calculator (Java 21 + JUnit 5)

Реализация базового калькулятора с четырьмя арифметическими операциями (`add`, `subtract`, `multiply`, `divide`), консольной демонстрацией сценариев и набором модульных тестов на JUnit 5.

## Требования
- JDK 21
- Apache Maven 3.8+ (опционально, для автоматического запуска тестов)

## Запуск через Maven

Запуск модульных тестов:
```bash
mvn test
